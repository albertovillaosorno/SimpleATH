# Security policy

SimpleATH is an experimental kernel-facing project with no stable supported
release or security support SLA. It has not been validated for production use.

Please report a potentially exploitable issue privately using GitHub's
repository security advisory workflow if available. Do not publish private
keys, crash dumps containing sensitive memory, machine serial numbers,
access tokens, macOS provisioning profiles or device-specific personal logs.

For reproducible issues, include the affected revision, a minimal description
and redacted reproduction steps. Kernel and wireless failures can compromise
system availability: tests should run only on systems with recoverable backups.
